\# Gym Management System



Website quản lý cho một phòng tập gym, được xây dựng trong khuôn khổ đồ án ngành.



\## Công nghệ dự kiến



\- Backend: Python Django

\- Frontend: HTML, CSS, JavaScript, Bootstrap 5

\- Database: Microsoft SQL Server



\## Nhóm người dùng



\- Quản trị viên

\- Lễ tân

\- Huấn luyện viên

\- Hội viên



\## Trạng thái



Đã hoàn thành phân tích nghiệp vụ, BFD, DFD và ERD.  

Đang chuẩn bị khởi tạo Django project và cơ sở dữ liệu.
